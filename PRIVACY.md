# Privacy Policy

**Effective date:** 2026-07-26

## Scope

This policy describes the current Shift Feel application source code and the builds produced from it. It must be reviewed and updated before adding analytics, advertising, accounts, cloud services, crash reporting, or new third-party SDKs.

## Data handling

The current application does not implement user accounts, analytics, advertising, remote APIs, cloud synchronization, or telemetry. Driving controls and simulation state are processed on the device and are not transmitted by the application.

The optional FMOD integration processes audio locally. FMOD SDK files and sound assets are supplied locally by the developer and are not downloaded or transmitted by the app source code.

## Third parties

The app uses open-source dependencies and may optionally integrate FMOD. See [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) for distribution and licensing information.

## Changes

If the application begins collecting, sharing, storing, or transmitting personal data, this policy and the required store disclosures will be updated before that version is released.

## Contact

For project questions, open a GitHub issue. Do not report security vulnerabilities or include personal data in a public issue; follow [SECURITY.md](SECURITY.md) instead.
